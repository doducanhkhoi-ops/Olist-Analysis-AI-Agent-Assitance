# Dashboard Spec

Use this skill before building a dashboard.

## Workflow

1. Identify audience, decisions, cadence, and actions.
2. Define metric cards, trend charts, breakdowns, tables, filters, and alerts.
3. Add data freshness, owner, definitions, and caveats.
4. Remove vanity charts that do not drive action.

## Output

Return `Dashboard purpose`, `Wireframe spec`, `Metric definitions`, `Filters`,
and `Alert rules`.
